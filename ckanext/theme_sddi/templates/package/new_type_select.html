Über den SDDI Katalog

Dieser Katalog ist Teil der Smart District Data Infrastructure (SDDI) – einem offenen, modularen Rahmenwerk zur Verwaltung von Daten, Diensten und Ressourcen für urbane digitale Zwillinge.

Für jede Hauptkategorie steht eine vordefinierte Metadatenmaske zur Verfügung. Whlen Sie die Hauptkategorie aus, die der Informationsressource entspricht, die Sie als Katalogeintrag erstellen möchten.

Weitere Informationen zur SDDI-Methodik: Lehrstuhl für Geoinformatik, TU München

Hauptkategorien

Datensatz und Dokumente

Enthält Dokumente und Informationen zu jeder beliebigen Informationsressource einer Stadt, die als Dateien entweder im Katalog selbst oder an anderer Stelle gespeichert sind.

Online-Dienst

Enthält Daten, die über eine API bereitgestellt werden und keine Endbenutzeroberfläche haben (z. B. Web Feature Service, der Zugang zu Geodaten bietet).

Projekt

Umfasst alle geplanten, begonnenen oder abgeschlossenen Aktivitäten, die zur Erreichung eines bestimmten Ziels oder einer bestimmten Aufgabe führen.

Software

Repräsentiert ein spezifisches Werkzeug oder System, z. B. den FROST Server für die OGC SensorThings API oder spezifische Bibliotheken wie citygml4j.

Online-Anwendung

Enthält Daten, die über eine API bereitgestellt werden, und verfügt über eine Benutzeroberfläche (z. B. für die Erkundung von Online-3D-Simulationen).

Methode

Stellt Funktionen oder Algorithmen dar, die von einem Experten entwickelt wurden, um eine bestimmte Aufgabe zu erfüllen (z. B. ein Algorithmus zur Analyse des Sonnenpotenzials).

Gerät / Ding

Umfasst alle physischen Geräte, wie z. B. Sensoren und Aktoren.

Geoobjekt

Ein Objekt mit einer klar definierten geografischen Komponente (z. B. Gebäude, Straßenlaterne, Bank).

Digitaler Zwilling

Eine Sammlung digitaler Ressourcen für ein bestimmtes Thema oder geografisches Gebiet – vergleichbar mit einem Warenkorb, in dem alle Informationsressourcen für einen Anwendungsfall gesammelt werden.
